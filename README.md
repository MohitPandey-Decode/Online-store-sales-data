
Online Store Annual Sales Analysis Dashboard – Excel Project

This project presents an end-to-end Annual Sales Analysis Dashboard built in Microsoft Excel. The objective was to transform raw, unstructured data into a decision-focused reporting system that highlights revenue performance, customer behavior, fulfillment efficiency, and channel contribution.

Project Overview

The dashboard provides a consolidated view of:

State-wise sales performance

Gender and age-group contribution

Order status analysis

Online channel sales share

Monthly sales trend

Key customer segments

The goal was to enable commercial visibility and support business planning through structured analytics.

Data Processing Steps

To prepare the dataset for analysis, the following transformations were performed:

Month Extraction: Created a new column by extracting month information from the Date field.

Age Group Classification: Categorized customers into Youth, Adult, and Senior Citizen based on age.

Order Status Standardization: Cleaned and normalized status labels (Delivered, Returned, Refunded, Cancelled).

Channel Mapping: Standardized platform names (Amazon, Myntra, Flipkart, etc.) for accurate channel analysis.

These steps ensured a clean, consistent dataset suitable for pivot-driven reporting.
